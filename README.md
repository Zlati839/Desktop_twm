# Twm Desktop helper
A desktop buddy designed after Twm from the game OneShot

# Current Features 
They can teleport around your screen and give a greeting when they are first booted up , also randomly speaks and has special dialog that
depend on hour of the day , system uptime and system username . Also if you shake the window around Twm will get dizzy and complain  

# Future palns
I want them to be able to shift around icons and push windows and as well get out of their window and configurations
